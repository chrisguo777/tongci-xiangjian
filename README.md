# 同词相见 · 双人在线版

双人实时词语联想游戏：创建房间 → 分享链接 → 双方秘密提交 → 同时揭晓 → 逐轮联想 → 同词获胜。

无需注册登录，手机竖屏优先，电脑同样适配。

## 游戏规则

- 第一轮，各自随意写一个词，不要提前讨论。
- **两人都提交后**才同时揭晓，提前看不到对方的答案。
- 不一致时，下一轮各自根据刚揭晓的那两个词联想（界面会一直显示这两个词）。
- 某一轮两人写出同一个词即获胜（忽略首尾空白和大小写），显示用了多少轮。
- 随时可以「再玩一局」。

## 本地运行

要求 Node.js 18+（推荐 20/22）：

```bash
npm install
npm start
```

打开 http://localhost:3000 。

本机想一个人测两边：开**两个标签页**即可——玩家身份存在 `sessionStorage` 里，每个标签页是独立的一名玩家。

## 测试

```bash
npm test
```

21 条 Node 内置 test runner 用例，覆盖：先后/同时提交、重复提交、空词、同词判定、换轮幂等、过期轮次提交、房间满员、刷新与断线重连、第二标签页顶替、重新开始、退出让位、长度截断、`/health` 与首页。

## 部署到 Render（免费）

仓库里已经有 `render.yaml`，两种方式都可以：

**方式 A · Blueprint（推荐）**

1. 打开 https://dashboard.render.com/blueprints ，点 **New Blueprint Instance**。
2. 连接这个 GitHub 仓库，Render 会自动读取 `render.yaml`。
3. 点 **Apply**，等待首次部署完成。

**方式 B · 手动建服务**

1. Render 控制台 **New → Web Service**，连接这个仓库。
2. Runtime: **Node**；Build Command: `npm install`；Start Command: `npm start`；Instance Type: **Free**。
3. 不需要手动配置端口，服务读取 Render 注入的 `PORT`。WebSocket 在 Render 上开箱可用，无需额外设置。

部署完成后打开 `https://<你的服务名>.onrender.com` 即可。

## 怎么和对方进入同一个房间

1. 一方打开网址，填昵称，点**创建房间**。
2. 点**复制邀请链接**，把链接发给对方（微信/短信都行）。
3. 对方点开链接，填昵称，点**进入房间**——两人就在同一个房间了。
4. 也可以口头报 6 位房间码，对方在首页点「加入对方的房间」手动输入。

## 使用限制

- 每个房间最多两名玩家；房间只存在服务器内存中，服务重启、重新部署或 12 小时无活动后失效。
- Render 免费实例会在闲置约 15 分钟后休眠，**休眠会清空所有进行中的房间**，再次打开需要几十秒冷启动。
- 不用数据库，不收集账号；联想词会保存在服务器内存直到房间过期，请不要输入隐私信息。
- 房间码只是分享凭据，不是高强度访问控制。
